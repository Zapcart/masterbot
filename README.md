# 🚀 Ark Algo Labs – Innovative Digital Solutions

**Ark Algo Labs** is a modern, high-performance digital solutions website built to showcase expertise in **E-commerce development** and **Algorithmic Trading Automation**.

The project focuses on **clean UI, smooth animations, strong branding, and conversion-focused design**, making it suitable for startups, agencies, and tech consultants.

---

## 🌟 Highlights

- 🎨 Premium Teal & Orange brand theme
- ⚡ High-performance, lightweight frontend
- 🧠 Business-focused content structure
- 📱 Fully responsive (Mobile / Tablet / Desktop)
- 💬 Floating WhatsApp CTA for instant leads
- 🎬 Scroll-based animations using Intersection Observer
- 🧭 Smooth navigation with fixed header

---

## 🛠️ Tech Stack

**Frontend**
- HTML5  
- CSS3 (Custom design system & animations)  
- JavaScript (DOM, Scroll, Intersection Observer)

**Libraries & Assets**
- Google Fonts (Poppins)
- Font Awesome Icons
- WhatsApp Click-to-Chat API
